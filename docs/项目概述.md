
# 项目概述

## 项目背景
本项目为ICSI499课程项目，是一个物品管理系统，允许用户注册、登录、添加物品、搜索物品、查看物品详情等功能。

## 项目目标
1. 实现用户身份验证系统
2. 提供物品管理功能（添加、编辑、删除、搜索）
3. 实现基于位置的地图展示功能
4. 创建用户个人资料管理功能

## 功能概述
- **用户管理**：注册、登录、个人资料管理
- **物品管理**：添加物品、编辑物品、删除物品、物品搜索
- **地图功能**：展示物品位置
- **用户物品列表**：查看用户关联的物品

## 技术栈
- **前端**：Angular框架
- **后端**：Node.js + Express
- **数据库**：MySQL
- **地图服务**：集成第三方地图API

## 架构类型
本项目未使用GBF框架，采用传统分层架构：
- 前端：Angular组件化架构
- 后端：RESTful API服务
- 数据库：关系型数据库存储
