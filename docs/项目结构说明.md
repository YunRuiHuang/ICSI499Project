

# 项目结构说明

## 项目模块划分
1. **前端模块**：Angular应用 (frontend/CourseProject)
2. **后端模块**：Node.js API服务 (database/Interface)
3. **数据库模块**：MySQL数据库配置 (database/config)

## 代码组织结构
```
├── database             # 后端服务
│   ├── Interface        # Node.js应用
│   │   ├── config       # 数据库配置
│   │   ├── router       # API路由
│   │   └── app.js       # 应用入口
├── frontend             # 前端应用
│   └── CourseProject    # Angular项目
│       ├── src/app      # Angular组件和服务
│       │   ├── items    # 物品管理功能
│       │   ├── users    # 用户管理功能
│       │   ├── map      # 地图功能
│       │   └── shared   # 共享服务和模型
```

## 关键包说明
- **前端**：
  - `items`：物品管理相关组件（添加、编辑、搜索、列表）
  - `users`：用户管理相关组件（注册、登录、资料）
  - `map`：地图展示组件
  - `shared`：共享服务和数据模型

- **后端**：
  - `router`：API路由处理
    - `items.js`：物品相关API
    - `users.js`：用户相关API
  - `config`：数据库连接配置

## 分层架构说明
1. **表现层**：Angular组件 (frontend)
2. **业务逻辑层**：Node.js路由处理 (database/Interface/router)
3. **数据访问层**：MySQL数据库操作 (SQLoperate.js)
4. **数据存储层**：MySQL数据库

## 未使用GBF框架说明
本项目未使用GBF框架，采用传统的分层架构模式，各层职责明确：
- 前端负责用户界面和交互
- 后端负责业务逻辑和数据处理
- 数据库负责数据持久化存储
